This project presents the modelling and simulation of a non-inverting two-switch buck-boost DC-DC converter for electric vehicle applications in MATLAB Simscape. The converter regulates a 48V DC output from a battery source that varies between 42V and 60V across a full discharge cycle, represented by real-world CSV data imported into Simscape.
The topology uses two MOSFETs and two diodes in a non-inverting configuration, selected over the conventional single-switch inverting topology to maintain positive output polarity — consistent with production EV battery management systems. Component values (L=1mH, C=110µF, R=24Ω) were derived analytically for continuous conduction mode operation at 20kHz.
Mode selection uses a Relay block with hysteresis to prevent chattering at the crossover voltage. A three-gate logic network (AND, OR, NOT) routes the PWM signal to the correct switch in each operating mode without requiring separate constant signal sources. A discrete PI controller with anti-windup clamping adjusts duty cycle in real time based on the error between measured output voltage and the 48V reference. The complete closed-loop model was validated through simulation, confirming output regulation within ±0.4V and CCM operation across the full input voltage range.
